Polityka prywatności — PersonalOS Local

Obowiązuje od 4 listopada 2026.

Kto i po co

PersonalOS Local jest prywatnym narzędziem jednej osoby (właściciela). Jedynym użytkownikiem i jedyną osobą, której dane są przetwarzane, jest właściciel. Narzędzie nie jest udostępniane innym osobom.

Jakie dane z Google

Narzędzie korzysta z Gmail API z zakresem tylko do odczytu (https://www.googleapis.com/auth/gmail.readonly) dla konta właściciela. Odczytuje nagłówki i treść wiadomości, aby lokalnie je indeksować, wyszukiwać i klasyfikować (np. rachunki, zamówienia, terminy). Nie wysyła, nie usuwa i nie modyfikuje wiadomości ani etykiet.

Przechowywanie i udostępnianie

  • Dane są zapisywane wyłącznie na urządzeniach właściciela (komputer, w przyszłości domowy serwer) i w jego zaszyfrowanych kopiach zapasowych.
  • Narzędzie nie sprzedaje danych, nie używa ich do reklam i nie przekazuje ich osobom trzecim.
  • Tokeny dostępu są przechowywane lokalnie na koncie systemowym właściciela.

Limited Use

Korzystanie przez PersonalOS Local z informacji otrzymanych z interfejsów API Google i ich przekazywanie jest zgodne z Google API Services User Data Policy, w tym z wymaganiami Limited Use.

Cofnięcie dostępu i usunięcie danych

Dostęp można w każdej chwili cofnąć na stronie myaccount.google.com/permissions. Usunięcie lokalnej bazy danych usuwa wszystkie pobrane dane.

English summary

PersonalOS Local is a personal, single-user tool. Its only user and only data subject is its owner. It uses the Gmail API with the read-only scope gmail.readonly for the owner's own account to index, search and classify the owner's email locally. It never sends, deletes or modifies email. Data and tokens are stored only on the owner's own devices and encrypted backups; they are not sold, not used for advertising and not shared with third parties. PersonalOS Local's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
